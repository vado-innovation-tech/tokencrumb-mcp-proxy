# Security policy

Please report suspected vulnerabilities privately:

- GitHub: **Security → Report a vulnerability** (private vulnerability reporting), or
- email: [security@tokencrumb.ai](mailto:security@tokencrumb.ai)

Do not open a public issue. Include the affected version or commit, the
configuration, expected and actual behavior, and a minimal reproducer with
synthetic keys and data. Never send operational keys or live tokens.

Supported versions: the latest release and the `main` branch.
We aim to acknowledge reports within a week (best effort).
