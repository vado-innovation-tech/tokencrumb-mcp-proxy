# Roadmap

The current focus is a small, auditable MCP authorization proxy. This list describes priorities, not release commitments.

- Extend independent issuer and MCP client interoperability coverage.
- Define and validate coordinated state storage before supporting multiple hosts.
- Improve operational observability without exposing capability contents or credentials.
- Evaluate additional MCP methods only with explicit authorization and transport semantics.

Use issues to propose a concrete use case, trust model and acceptance criteria.
